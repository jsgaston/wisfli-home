The plan

Wisfli is one person: me, Javier. No team, no fund, no office. Here's where the project is going, in the order it has to happen.

01

Build the fleet

Fifty to a hundred bots, each with its own logic, all on the same account. Each one gets out-of-sample testing before it trades, and gets switched off if it stops working. Many small, unrelated edges are safer than one big bet.

02

Take it on the road

The bots run on a server, not on my desk. If the fleet holds up and pays its way, I'll move abroad and keep building from wherever I am.

03

Share the signal

The aim is to offer the fleet's signal to more than 500 families who need it, to help them out of poverty. I'm still working out the conditions, and I'll publish them here before anyone joins.

What this is not

This is a goal, not a promise. The account can lose money, and when it does this page will show it. No return is promised or implied to anyone, and nobody should put in money they need.
